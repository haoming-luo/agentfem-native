## 热与线性耦合

仿射 d 维单纯形有 m=d+1 个节点，正体积 V，梯度 G[a,J]。
K_ab=V G_a k G_b；C_ab=rho*c*V*(1+delta_ab)/(m*(m+1))。
后向 Euler： (C/dt+K) T[n+1]=C T[n]/dt+q[n+1]。
热流 q_phys=-k grad(T)。边界输入为向内热通量，故正值进入右端。
Robin 为 h(T-Tambient)，左端添加面质量乘 h，右端添加 h*Tambient 面积分。
每步记录 C(Tnew-Told)/dt+K*Tnew-q 的约束反力以及全局热量余额。
瞬态热和 T4 动力的规划先检查整个时间区间有限、相邻时间可表示；具体准入沿用
`LINEAR_DYNAMICS.md`，不因单个 dt/steps 合法就承诺无限终点可执行。
导热张量仅允许相对最大分量 `64*eps` 的舍入级非对称，并取对称均值；不得以
NumPy 默认绝对容差让微小量纲下的非对称张量通过正定准入。

附加轻量解析证据：对 x=.5 对齐网格的两层导热，T(0)=0、T(1)=1，热阻
R=.5/k1+.5/k2，`q_x=-1/R`，温度在各层斜率为 `1/(R*k_i)`。
旋转 R 后，张量和温度梯度分别变换为 `R*k*R^T`、`R*gradT`，热流也应按
`R*q` 旋转。齐次固定温度、无热源/入热流时，后向 Euler 满足
`(Tnew^T C Tnew-Told^T C Told)/2 + dt*Tnew^T K*Tnew + deltaT^T C deltaT/2=0`。
这里 C 范数是离散耗散恒等式，不将温度平方量误称为物理储热；实际储热仍是
`1^T C T`。三项证据覆盖材料跳变、坐标变换及完整时间步，不扩大到任意网格。

热弹性 sigma=D*(B*u-eps_th)，f_th=integral B^T D eps_th。
三维 eps_th=alpha*(T-Tref)*[1,1,1,0,0,0]。
二维平面应力有效热应变为 alpha*dT*[1,1,0]；平面应变为
(1+nu)*alpha*dT*[1,1,0]，恢复 sigma_zz 时须使用真实三维热应变。
这是温度驱动力学的顺序单向耦合，不声称热弹性阻尼或机械耗散热反馈。

热弹性候选的 E、nu 可为统一标量或与单元顺序对应的有限数组；每单元满足
E>0、-1<nu<.5，计算得到的 mu、lambda 也须有限，mu 不得下溢为零。逐单元使用同一各向同性
公式及热应变/温度方差能量；材料仅在单元间跳变，不在单元内插值。标量和
等值数组必须给出相同装配与场量。准备时复制并只读保存参数快照，不让调用方
改变原数组影响既有算子。其他候选 JSON 暂仍要求标量弹性参数。

轻量真值：nu=0、x=.5 处相接的两层条带，在单位参考端面力下
`u_x=min(x,.5)/E1+max(x-.5,0)/E2`，其余分量为零，sigma_xx=1，
应变能为 `.5*(.5/E1+.5/E2)`（单位横截面）。这验证对齐材料界面的跳变，
不代表任意非共形界面、界面脱粘或近不可压缩混合公式。

### 候选工程载荷输入

候选 0.4 增加可选 `mechanical.body_force`（d 维常向量，每单位参考体积的力）及
`mechanical.tractions`（命名外边界集合到 d 维常向量的映射，每单位参考面积的
力）。已有 `mechanical.load` 仍是每节点总力；三者明确相加，不隐式替换或乘
密度。单纯形体力每节点为 V*b/(d+1)，边界面力每节点为 A*t/d；二维 V/A 均
乘显式厚度。共享节点累加；重叠命名集合也按用户给出的载荷项叠加。

预检拒绝向量维度/有限性错误、未知或空边界、非对象映射；纯热问题仍拒绝全部
力学字段。预算/取消在载荷积分前生效。热弹性和 T4 动力接收常载荷；有限变形与
AT2 对组合后的完整参考载荷使用既有加载因子。大变形中的方向/参考面积固定，
不接受 `pressure` 或随动载荷，不改变几何或随动切线。

这属于非稳定候选的可选字段扩展：旧请求语义不变，稳定 0.1/0.2/0.3 不变。
能力清单明确列出载荷形式；旧版本二进制的未知字段拒绝行为不删除。
最低证据为总力/力矩与厚度恒等式，二维/三维类型化载荷到候选结果的完整对照，
以及非法边界与预算前置失败。不能仅用两个相同积分入口互相比对当作物理真值。

## 有限变形

F_iJ=delta_iJ+sum_a u_ai G_aJ，二维使用 F33=1 的平面应变嵌入。
沿用已记录的可压缩 Neo-Hookean W(F)，J>0；A_iJkL=dP_iJ/dF_kL：

`A_iJkL=mu*delta_ik*delta_JL+lambda*FinvT_iJ*FinvT_kL+(mu-lambda*ln J)*FinvT_iL*FinvT_kJ`。

r_ai=V*P_iJ*G_aJ-f_ai，K_ai,bk=V*G_aJ*A_iJkL*G_bL。
可选均匀逐单元热伸长 s=1+alpha*(T-Tref)>0，Fe=F/s，使用
W_ref(F,T)=W(Fe)，P=P_e/s，A=A_e/s²；明确能量以参考体积计。
Newton 用真实自由残差收敛；试探 J<=0 拒绝；线搜索缩步；失败增量二分。
已接受位移不被拒绝试探修改。一般切线未必正定，不能假设 CG 一定适用；
使用自主重启 GMRES 或显式可选通用提供者。当前不跟踪极限点后的平衡分支。
自由横向收缩单轴拉伸的独立对照：轴向伸长 s、相等横向伸长 t 满足
`mu*(t²-1)+lambda*log(s*t^(d-1))=0`，二维保留 F33=1。
轴向参考面力为 `mu*(s-1/s)+lambda*log(s*t^(d-1))/s`。约束采用对称面法向
滚动约束及轴端位移，不将横向全部锁死；检查位移、反力及自由横向应力为零。
取消可在 Krylov/Newton/交替迭代安全检查点发生，错误只附带已提交状态；不是
已有持久化检查点协议。程序内迭代计数不冒充物理步数预算。

固定拓扑、固定约束的 Newton 在首次线性求解时准备一次 `CSRConstraintPlan`，
后续只变换当前切线的数值与右端；不得复用旧切线或旧数值预条件器。缓存局限于
一次 `solve` 调用，图或约束不一致必须拒绝。Python 诊断开关
`reuse_constraint_plan=False` 仅用于等价与完整求解计时，不改变物理输入/容差。

下一性能实验采用解析缩并，而不是更换材料定律。令 `v_ai=G_aJ*Fe^-T_iJ`，
`c=mu-lambda*log(Je)`，则同一局部切线可以写为
`K_ai,bk=(V/s²)*(mu*delta_ik*(G_a·G_b)+lambda*v_ai*v_bk+c*v_ak*v_bi)`。
它避免先生成四阶材料张量再双重收缩；基准 `tangent_form=tensor` 仍是默认，
`tangent_form=factorized` 作为显式 Python 实验选项，未进入 JSON 契约或生产
默认。必须比较完整刚度、内力/能量及非线性轨迹，性能只在测量范围内声明。

## 拓扑与刚体准入

### 请求快照与进度回调

候选 JSON 的规划和执行在入口复制完整请求，再校验、生成摘要并执行；回调可以
修改调用方持有的原请求，但不能改变本次计算的材料、载荷、约束、预算或关联 ID。
成功与失败的关联 ID 都来自同一快照。不通过事后重新计算摘要掩盖已被改变的模型。
这不承诺对调用前/复制过程中的跨线程并发写入提供原子性；调用方仍须同步共享
输入。复制属于输入接纳开销，资源预算仍不是 JSON 输入大小或进程 RSS 硬限制。

候选单纯形算子拒绝未被任何单元使用的节点。按单元节点邻接连通分量检查零空间：
稳态热要求每个分量至少一个固定温度或正 Robin 面；力学要求每个分量的受约束
刚体迹达到二维 3 / 三维 6 的秩。刚体基先去掉该分量的原点并按几何尺度归一化，
因此不会仅因模型平移或长度单位改变而改变判定。该检查是必要条件，不替代铰接
机构、零能模式或病态条件数检测；不得把无载荷零残差视为唯一解证明。

## T4 线性动力候选

三维一致质量 `M_ai,bj=rho*V*(1+delta_ab)*delta_ij/20`；集中质量为行和。
复用已存在的中心差分/Newmark 程序，但 T4 空间能力只标记 implemented。
候选 JSON 的 `linear_dynamics_t4` 仅接纳三维实体、恒定节点力、零固定约束、
有限初始位移/速度与 Newmark 平均加速度；质量形式为 `lumped`/`consistent`。
时间步和步数必须为正；至少存在一个自由 DOF。先校验初值满足约束、材料密度、
连通分量和资源预算，再构造质量/刚度。结果沿用通用动力学的时间历史、反力、
动能/应变能/外功与能量余额，数组按节点优先 xyz 展平。该 JSON 入口不接纳
重启、阻尼、时变载荷/约束或显式积分；Python API 的既有能力不据此删除。
质量/模态时间阶/零约束/重启证据不等价于三维波传播完整验证。

三维纵波的独立证据选取单位长度、横向位移完全抑制的 T4 条带，左端 ux=0，
右端自然边界。连续场 u=(U(x,t),0,0)，满足 rho U_tt=(lambda+2mu) U_xx。
解析波速 `c=sqrt((lambda+2mu)/rho)`，最低圆频率 `omega=pi*c/2`；不将其
误认为自由横向收缩细杆的 `sqrt(E/rho)`。一致质量检查 8/16/32 的频率空间
二阶趋势；集中质量采用局部高斯位移起振、0.2 倍保守显式步长，在反射返回前
测量 x=.5/.75 两截面平均位移的峰值到时，以速度误差与能量偏移的下降为证。
初始峰中心 x=.2、宽度 .04；初始速度为零，左端严格清零。该证据仅针对纵向
约束条带，不覆盖三维自由表面横波、复杂模态或任意畸变网格。

## AT2 准静态脆性断裂

采用各向同性无张压分裂模型：
E(u,d)=integral [((1-d)^2+kappa)*psi0(eps(u))+Gc/(2ell)*d²
+Gc*ell/2*|grad d|²] dV - f^T u。
每单元 B*u 常量，损伤使用 P1：积分 (1-d)^2 必须使用一致单纯形质量，
不能用单元平均损伤平方代替。固定 u 时
A_d=(2psi0+Gc/ell)*M0+Gc*ell*K0，b_d=2psi0*V/m。
在 d_previous<=d<=1 的箱约束内求解凸二次子问题，并检查 KKT；不能只截断
无约束解。交替位移和损伤直至场变化与平衡残差都满足容差，再接受整步。
不使用历史最大能量替代变分约束，因此有同一离散势能的下降检验。
本模型会在压缩下损伤，仅为隔离候选；不用于裂面闭合、压缩断裂或混合模态
工程结论。预裂纹可由初始 d=1 节点给出；加载卸载不允许愈合。

## 数学资料与独立性

后续轻量制造解：单位方形/立方体 `T=sum_i x_i(1-x_i)`，`k=1`，体热源
`q=2*d`，外边界固定解析温度。热弹性平面应变/三维使用 `u_i=x_i²`，
`T=Tref+sum_i x_i`，常数 alpha。均匀材料体力每分量为
`-(4*mu+2*lambda)+(2*mu+3*lambda)*alpha`。在 4/8 划分上，检查体积加权
单元重心采样误差：温度/位移二阶、热流一阶；这里是声明的采样范数，不是精确
积分 L2 误差，也不代替更广的非结构网格验收。真值由方程代入得到，不依赖其他
有限元软件。
