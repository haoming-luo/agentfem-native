# 可复用 CSR 稀疏图规格 0.1

**状态：** 参考数据层实现候选

## AgentFEM 使用场景

多载荷工况、隐式动力和未来 Newton 迭代会在同一 DOF 拓扑上反复更新矩阵数值。
如果每次都重新排序 COO 并归并重复项，符号工作会被无意义地重复。Native 需要把
“矩阵在哪里非零”与“这一次非零值是多少”分开，并让 Agent 在执行前识别图身份
和内存成本。

## 数据契约

`CSRPattern` 是不可变、规范有序的标量稀疏图，包含：

- `shape`：非负、有符号 64 位可表示的矩阵尺寸；
- `indptr`：长度为 `row_count + 1` 的规范 CSR 行指针；
- `indices`：每行严格递增的规范 CSR 列索引；
- `coo_to_csr`：每个原始 COO 贡献项对应的规范 CSR 数值槽位。

图从 rows/columns 或二维单元 DOF 表创建一次。创建时按行、列、原输入顺序排序；
同一 `(row, column)` 的重复贡献共享一个数值槽位。所有索引数组复制后设为只读，
不保留调用方可变视图。

## 数值回填

`fill(values)` 要求一维、有限、长度与 `coo_to_csr` 相同的 binary64 数值。回填
按照原始贡献顺序累加到预分配的规范槽位，返回新的不可变 `CSRMatrix`；图数组由
结果安全共享，数值数组不得在不同矩阵间共享可写状态。

必须满足：

1. 首次回填与 `CSRMatrix.from_coo` 完全一致；
2. 任意次数回填不重新排序 rows/columns，也不修改图；
3. 相同输入逐位可重复；
4. 空图、空行、重复贡献和显式零值具有稳定语义；
5. 长度、非有限数值、越界索引、无效形状和无效单元 DOF 必须显式失败；
6. 参考层不依赖 SciPy、PETSc 或第三方有限元实现。

## 成熟度边界

0.1 只建立可执行参考契约，不宣称 C++ 数值回填或端到端重复求解已经完成。生产
C++ 路径必须复现本规格，并在实际 T3/T4 多次装配中证明省去符号排序的收益后
才能接纳。
