# ADR 0034 IC0 强预条件器隔离实验

状态：实验，不替换 Native 稀疏默认路径。

## 决策

面向 AgentFEM 较大稀疏静力与隐式系统，先验证无新增填充的对称不完全 LDLT
预条件器。分解由项目自己的 CSR 和明确数学递推拥有；可读三角应用始终存在。
SciPy 仅可作为显式、可替换的三角求解加速提供者，不能拥有单元、约束、材料或
外层 CG 语义。不导入第三方有限元实现，不新增必需依赖。

默认 `native_sparse`、Jacobi/块 Jacobi、稳定契约保持不变。实验只有显式 Python
对象入口，不进入 JSON 或科学 Gate 的生产声明。晋级必须同时看到真残差、场量
和包含准备成本的端到端收益，不能只报告迭代次数减少。

## 风险与否决条件

SPD 原矩阵也可能在 IC(0) 中出现非正枢轴；立即拒绝，并报告行号。允许调用方
显式给定非负对角平移，只改变预条件器，不改变求解方程；不得自动重试、添加
未知平移、删除误差或把缺少可选提供者误报成数值成功。

Python 串行三角循环可能抵消减少迭代的收益。若成立，只留下数学与机制证据，
后续再评估自有 C++ 三角应用，而不是把未测的外推当作已取得的高性能。

第一阶段筛选确认两段开销均需处理：三档模型的迭代明显减少，但含准备的总成本
更高。第二阶段同时实现 C++20 IC0 递推及三角应用，作为 ABI 1.6 增量，旧 ABI
函数签名不变；仅 `backend="native"` 显式调用。新的原生函数必须完成 buffer
与索引检查、非正枢轴/非有限失败、C11/C++ 契约、sanitizer 和 Tier-1 平台门禁。

理论参考为 Netlib《Templates》的不完全分解说明；只阅读理论文字，不以算法
源码为输入： https://netlib.org/linalg/old_html_templates/section2.7.4.html

## 有界测量与当前结论

macOS arm64，T3 578/4802 DOF、T4 2187 DOF，各向节点力分别形成 2/2/3 个
右端项；显式缩放后平移 sigma=.1，E=100、nu=.25。固定规范约束 CSR 之后，
计入准备和全部 CG 求解，排除网格、装配及导入。

初版参考和可选 SciPy 路线虽然约减少 3 倍迭代，总成本仍劣于 Jacobi。仅迁移
C++ 递推/应用也未全面获益；剖析定位到重复转置 CSR、下三角 COO 排序与对象
校验。源图已经规范，镜像槽位分析与筛选可直接保持结构不变量；移除重复构造，
保留最终 CSR 和 C ABI 的输入校验。

选定组合后，独立五次交错确认的总求解中位倍率为 1.71×、1.58×、1.14×。
迭代数依次由 [216,219]、[669,656]、[150,207,207] 降至 [63,63]、[186,183]、
[51,71,71]。场量、应变能和真残差按既有门槛通过。证据在
`benchmarks/results/2026-10-27-ic0-native-confirmation.json`，包含源码摘要。
这是限定规模与平移的本机结论，不是所有 SPD、Windows 或 PETSc 对比结论。
非正枢轴反例保持失败；当前只支持显式实验，默认策略不晋级。

## 同图不同数值的后续实验

AgentFEM 材料扫描可显式持有 `IncompleteCholeskyPattern`，只复用镜像/下三角/
对角槽位分析，不复用旧 L、D、缩放或范数。每次 factor 精确匹配图并重新执行
全部数值准入与分解；成功对象绑定本次数值快照。失败不污染旧对象，无全局缓存。

四组 (E,nu)=(100,.2),(150,.25),(70,.3),(250,.15)，固定约束 CSR 后，每组
重新分解并执行 CG。五次交错，包含第一次结构准备，三档总求解中位倍率约
1.03、1.12、1.20；观察位移差 0，迭代数相同，应变能和真残差通过。结构计划
额外存储 O(nnz)，原始样本和实际字节见
`benchmarks/results/2026-10-27-ic0-pattern-reuse.json`。
小模型收益有限；不叠乘上一轮倍率，不外推有限元装配、Windows 或不同图重建。
ABI 不变，仍是隔离 Python 显式入口，未迁入默认提供者或 JSON。
