# ADR-0036：热弹性候选的逐单元材料参数

状态：implemented 候选，须独立验收，不晋级整个复合材料能力。

AgentFEM 需要组合不同实体/材料区域；候选通过网格单元顺序上的 E、nu 数组
表达离散材料，不依赖 AgentFEM 内部区域对象。Native 自己负责逐单元本构、
装配、热应变载荷、三维应力恢复与能量；网格/语义不交给通用线性代数库。

保留统一标量输入；标量与等值数组路径数学一致。参数由调用方输入后复制，
派生 Lamé 参数只读。除了原始参数范围，还拒绝计算后溢出的本构系数。二维
平面应力消元和完整三维热能均使用对应单元参数，不能用全局平均材料替代。

候选 JSON 只对 thermoelastic 开放；有限变形、AT2、T4 动力的 JSON 准入仍
限标量。Python 共享弹性算子的复用不构成材料跳变断裂已验证。没有新 C ABI、
必需依赖、界面单元或区域自动推断。最小证据：两层串联解析响应，标量/数组
等价，非均匀热应变能量导数、旧快照独立性及预检失败。
