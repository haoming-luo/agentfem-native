# ADR-0035：强约束值从 CG 初态开始精确满足

状态：修复候选；不改变方程、容差或预条件器。

## 证据与原因

两层导热 k=1e3/1e6、T4 4³、左右温度 0/1 的独立热阻解发现：零初猜的
全尺寸强约束系统会把单位约束行也近似求解。全局真残差满足约 8.76e-7 的
原始门槛，但固定节点温度差约 1.64e-11，被高导热率放大为约 3.31e-8 的
相对轴向热流误差。原先的 1e-8 热流判据失败，不能通过放宽它来隐藏。

同矩阵/相同容差/相同 Jacobi，仅在初态写入已知约束值后，约束误差为 0，
轴向热流相对误差约 4.68e-10，迭代仍为 27；真残差约 5.65e-7。该观测支持
修复约束状态不变量，不支持声称总体迭代或性能提升。

## 决策与不变量

强约束系统为 `A'=diag(A_FF,I_C)`、`b'_C=g`。令 `x0_C=g`，则初残差 C
分量为 0；Jacobi/块 Jacobi 在被清零的交叉行列上不混合自由和约束分量，故
所有搜索方向在 C 上均为 0，整个迭代保持 `x_C=g`。自由初猜仍为 0。
这不是事后夹紧输出，不修改 CG 报告、不替换原物理矩阵、不放宽真残差门槛。
全零约束保留原无显式初猜路径，避免给常见齐次问题添加不必要工作。

修复放在已拥有强约束语义的 NativeSparseSolvePlan，而非通用 CG 内部；普通
未约束 CG 不知道哪些行代表边界，也不应猜测。所有固定值均应满足、反力与
能量由原矩阵计算；全约束时已知解可零迭代成功。该修订须通过既有生产回归、
二维/三维热阻及新的标量/块预条件约束测试，再绑定新源提交验收。
