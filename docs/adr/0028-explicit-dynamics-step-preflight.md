# ADR-0028：显式动力稳定步长预检

**状态：** 已接受；Gate 3 线性动力本地候选

## 背景

中心差分只要求输入时间步为正，却没有在执行前拒绝可证明不安全的时间步。
AgentFEM 的计算代理因此可能得到数值爆炸后才发现模型不可用，也无法在计划阶段
解释显式时间步的安全余量。为了快速 Scrum 开发而直接计算大规模广义特征值，
又会引入昂贵、难以跨平台复现的求解步骤。

## 决策

对正对角质量矩阵，以

```text
lambda_bound = max_i sum_j |K_ij| / M_ii
dt_safe = 2 / sqrt(lambda_bound)
```

给出中心差分的充分、保守稳定上限。谱半径不超过该诱导无穷范数，因此
`dt <= dt_safe` 不会超过精确半离散临界步长；它不是精确特征值估计，也不能用来
宣称最佳时间步。

1. 质量矩阵必须只有正的显式对角项；否则中心差分继续明确失败；
2. `lambda_bound == 0` 时返回无穷上限，表示刚度没有给出有限稳定约束；
3. 中心差分执行前拒绝 `dt > dt_safe`，诊断同时给出请求值、上限和比值；
4. 约束动力先形成自由自由度主子系统，因此预检使用实际执行系统；
5. 计划层报告显式步长、保守上限和比值，但不影响 Newmark 平均加速度；
6. 使用项目自有 T3 质量/刚度构造离散模态，并以小型 NumPy 广义特征值对照只
   验证时间积分阶数；NumPy 不是有限元语义来源。

## 后果

- Agent 可在执行前解释显式时间步是否有保守安全余量；
- 不新增第三方依赖，也不把稠密特征值求解放入生产路径；
- 上限可能比精确临界步长更小，后续高性能 Lanczos/提供者估计必须另立规格；
- 本增量补齐安全预检、T3 时间细化和隐式重启证据，但不单独关闭波传播、完整
  Gate 3 或跨平台验收。
