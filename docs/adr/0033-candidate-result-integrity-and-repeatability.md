# ADR-0033：候选结果完整性与数值可重复性分开

状态：接受；日期：2026-10-27。

## 实际失败证据

`94e41cc` 的 Tier-1 运行 `40377566451` 在 Intel macOS 因重复求解结果摘要
不一致失败。没有先改容差，使用单任务 `40378446554`，在 macOS 15.7.9 x86_64、
Python 3.11.9、NumPy 2.4.6 上运行十条合成路线各 30 次，并记录前 3 次不同结果
的完整字段差异。本地 arm64 相同诊断未复现。

保留样本中的最大绝对差异：二维稳态热 1.24e-14、瞬态热 3.30e-14、热弹性
1.07e-14、AT2 1.72e-18；二维有限变形与五条三维路线在这次诊断中未变。
温度差异例如 30.000000000000004 与 30.0。所有既有解析、恒等式、残差等
科学测试均已通过。不能仅凭这些日志断定是某一个 BLAS 内核或线程调度导致；
这里只确认当前环境重复计算的浮点尾差，不宣称消除了通用浮点不确定性。

## 决策

`request_digest` 绑定规范请求，`plan_digest` 绑定确定性计划。
`result_digest` 则精确绑定本次完整结果载荷：不四舍五入、不截断、不删除残差，
任何载荷改变都应改变摘要。它是完整性凭证，不是跨运行/跨平台位相同承诺。
AgentFEM 不应把结果摘要相同作为数值等价或物理正确的替代判断。

修复原先错误的测试语义：逐份重算哈希核对其载荷，并核对重复执行的请求/计划
身份；热与损伤场另外以既有解析判据校核，保持原科学测试容差不变，不引入 OS
专属放宽。已声明逐位确定性的自有 CSR 回填、并行装配和限定重启测试不受此
候选契约决策影响。

候选证据显式报告 `result_digest_role=exact_payload_integrity` 与
`repeatability=numerical_tolerance_not_bitwise_guarantee`。若未来需要对整个
求解过程承诺位级重现，必须另设浮点/归约/运行库模式与性能成本验证，不能只
靠增加摘要字段。当前不为追求同一哈希修改通用数值库、数值结果或科学容差。

## 切线实验的后续边界修正

源提交 `96ac6b6` 的 Tier-1 `40383128457` 中，Intel macOS 的因子化切线测试
再次错误要求两个独立浮点调用的非切线输出逐位相同。日志明确显示应变能
1.512914 附近差 2.22044605e-16，相对差 1.47e-16；不是切线方向导数或完整
力学轨迹判据失败。该源提交整轮不可标为通过。

对这项“相同公式的重复输出”检查采用与字段单位同尺度的 binary64 舍入带：
最大绝对差不超过 `64*eps*max(abs(a),abs(b))`；零尺度仍要求精确零。不新增
平台分支，不改输出值，不扩大既有矩阵 1e-12、方向导数和完整轨迹的科学容差。
结构索引仍逐位比较。Intel 专用诊断补入这组测试，再验收变更来源。
