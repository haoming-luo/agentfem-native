# ADR-0029：复用 Newmark 固定有效矩阵的预条件器

**状态：** 已接受；Gate 3/P3 交叉增量

## 背景

固定时间步的 Newmark 平均加速度每一步都求解同一个有效矩阵
`M + beta dt^2 K`。当前实现已在时间循环外构造该矩阵，却在每次 CG 调用时重新
分析 Jacobi 对角。这种重复工作不改变结果，却违背 AgentFEM 让执行计划显式拥有
固定计算资源的方向。

## 决策

1. 在进入 Newmark 时间循环前，从有效矩阵构造一次 `PreparedPreconditioner`；
2. 每一步 CG 复用同一只读预条件器，并继续由其数值摘要拒绝矩阵失配；
3. 初始加速度的质量矩阵求解保持独立，因为它不是有效矩阵；
4. 不缓存到进程全局，不改变积分公式、容差、归约次序或检查点格式；
5. 能力清单显式报告 `implicit_effective_matrix_reuse`，但成熟度仍为
   `implemented`。

## 后果

- `N` 步 Newmark 从 `N+1` 次预条件器构造降为 2 次：质量矩阵一次、有效矩阵
  一次；
- 结果与迭代行为保持不变，重启后在新执行段重新准备一次资源；
- 这不是稀疏直接分解复用，也不宣称隐式动力性能已经完成；未来 IC(0) 或外部
  提供者仍须通过同一可替换边界进入。
