# ADR-0024：把可复用 CSR 图接入力学装配与提供者

**状态：** 已接受；实现与 Linux 快检通过

## 背景

ABI 1.4 已证明固定映射的数值回填可以跨平台稳定运行，但 T3/T4 求解仍通过
`COOMatrix` 让提供者每次重建 CSR。孤立回填能力不能直接转化为 AgentFEM 的
多载荷和时间步收益。

## 决策

建立小型、不可变 `CSRAssemblyPlan`，绑定单元 DOF 顺序与规范 CSR 图。T3/T4
增加显式预备与预备装配入口，求解函数可选接收计划。提供者边界扩大为同等接收
COO 或已规范 CSR，自有提供者直接消费 CSR。

不把计划隐藏在全局缓存，也不按对象身份猜测是否可复用。AgentFEM 或 Native
程序层显式拥有计划，拓扑不一致就失败；这样资源、生命周期和错误对 Agent 可见。

## 后果

- 固定拓扑的重复工程工作流不再重复构建稀疏图；
- 计划摘要可进入未来 KernelPlan、重启和提供者分析生命周期；
- 现阶段元素内核仍分配 COO 索引，峰值内存并未完全优化；
- 预条件器、约束图和材料/几何缓存需要后续独立规格与证据。
