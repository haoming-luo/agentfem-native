# ADR-0025：显式拥有固定矩阵的重复约束求解计划

**状态：** 已接受；本地实现、性能证据和 Linux 快检已闭环

## 背景

预备装配已经消除固定拓扑上重复构建 CSR 图的主要成本，但每个载荷工况仍重新分析
Dirichlet 约束、复制约束矩阵、构造 BSR 图并求逆对角块。这个生命周期不符合
AgentFEM 一次规划、多工况执行的使用方式。

## 决策

在自有稀疏层增加 `CSRConstraintPlan`，把约束图分析与数值应用分开；增加
`PreparedPreconditioner`，明确绑定生成它的矩阵图和数值；在自有提供者上增加
`NativeSparseSolvePlan`，持有源矩阵、约束后矩阵和预条件器，并对多个右端项重复
调用 CG。

计划均由调用方显式持有，不使用进程全局缓存。预条件器验证完整矩阵数值，防止
刚度更新后静默沿用旧逆对角。0.1 保持 Python 层 Kernel Contract 候选能力，不新增
C ABI；只有剖析证明 Python 边界成为主要瓶颈时才扩展 ABI。

## 后果

- 固定刚度多载荷不再重复约束矩阵和块预条件器准备；
- AgentFEM 可以把计划作为未来 KernelPlan 的受控资源；
- 改变矩阵数值需要显式重建数值预条件器，正确性优先于隐式缓存命中；
- 当前 CG 迭代和 SpMV 算法不变，因此数值收敛性质不被本决策扩大声明。
