# ADR-0009: source-available licensing boundary

Status: accepted by project owner — 2026-09-04

The model is unmodified PolyForm Noncommercial 1.0.0 for qualifying
noncommercial use plus a separate AgentFEM commercial license. Native must be
described as source-available, not OSI-approved open source. Commercial use
requires separate written permission. External contributions require recorded
acceptance of the repository CLA terms.
