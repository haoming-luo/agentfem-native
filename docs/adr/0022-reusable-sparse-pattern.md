# ADR-0022：分离规范稀疏图与数值回填

**状态：** 已接受，参考层候选

## 背景

现有 `CSRMatrix.from_coo` 每次都完成索引校验、排序、重复项发现和数值归并。
这适合一次性装配，但会拖累 AgentFEM 的多载荷工况、隐式动力和未来 Newton。
直接跳到 C++ 并发 CSR 写入会同时引入图算法、竞争策略和新 ABI，难以在一个
Scrum 增量中分清数学错误与性能错误。

## 决策

先在项目自有参考数据层建立不可变 `CSRPattern`：一次生成规范 `indptr/indices`
和原始贡献到 CSR 槽位的映射，随后只替换有限数值。`CSRMatrix.from_coo` 反过来
复用该契约，避免形成第二套规范化语义。

首个生产候选继续采用 COO 相同的局部矩阵顺序；后续 C++ 可以直接接收映射并
回填预分配数值，也可以在测量后采用着色或线程私有数值缓冲。无论实现如何，
图身份、原输入归约顺序和错误语义不能改变。

## 后果

- 可独立验证符号图、重复项归并和多次数值更新；
- 为计划摘要、预条件器 `analyze_pattern/update_values` 和状态重启提供稳定边界；
- 参考层仍会创建一次 COO 索引和映射，尚未消除生产装配的全部中间内存；
- 是否进入 C++ ABI 由代表规模的端到端收益决定，不因数据结构存在而自动接纳。
