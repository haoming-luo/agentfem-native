# P3 预备力学装配本地候选报告

**日期：** 2026-09-14  
**成熟度：** 本地 `implemented` 候选，等待远端 Linux 快检

## 产品价值

AgentFEM 在多载荷工况、材料参数扫描和线性动力建模中，可以显式创建并持有一个
`CSRAssemblyPlan`。只要网格连通性与 DOF 顺序不变，T3/T4 后续装配就复用规范
CSR 图；拓扑变化会在矩阵返回前失败，避免 Agent 静默使用错误缓存。

## 已完成

- 通用、不可变 `CSRAssemblyPlan` 保存单元 DOF 快照、规范图、映射、结构摘要、
  贡献数、非零数与存储量；
- T3/T4 均有显式 `prepare` 和 `assemble_prepared` API，求解入口可选接收计划；
- 自有、NumPy 和可选 SciPy 提供者均接受 COO 或已规范 CSR，自有提供者不会把
  CSR 转回 COO；
- T3 线性动力系统构建可以复用同一刚度图；
- 计划失配、贡献形状、越界 DOF、冷/热矩阵、求解和动力响应均有确定性证据。

本地 182 项测试、Ruff、格式与独立性扫描通过。新增 5 个高信息测试方法，覆盖
通用计划、T3、T4、SciPy CSR 和动力学接入。

## 声明边界与下一瓶颈

测量覆盖元素装配、COO 对象形成和规范 CSR 生成，不包含约束、预条件器或线性
求解。当前元素内核仍生成并复制 COO 行列索引；计划也保留单元 DOF 与贡献映射，
因此不能宣称零中间内存。下一步应测量多载荷完整求解，并分别设计约束图复用、
