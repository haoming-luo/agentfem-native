# 预备约束求解生命周期 0.1 验证报告

**日期：** 2026-09-14  
**成熟度：** `implemented`，本地验证通过；Linux 快检待运行  
**平台：** macOS arm64，Python 3.11.15，NumPy 2.4.6，C++ ABI 1.4

## 已交付能力

- `CSRConstraintPlan` 一次分析固定 CSR 图、约束集合、提升项和可能缺失的对角；
- 约束矩阵与右端项可分别更新，固定矩阵多载荷不再重复构造约束后 CSR；
- `PreparedPreconditioner` 固定 Jacobi/块 Jacobi 数值，矩阵图或数值变化明确失败；
- `NativeSparseSolvePlan` 由 AgentFEM 程序层显式拥有，不使用隐式全局缓存；
- CG 声明收敛前复算真实残差，并考虑 binary64 可达到的后向误差底线；
- 能力清单公开 `fixed_matrix_multiple_rhs` 范围与 `implemented` 成熟度。

## 正确性证据

新增用例覆盖非零且非排序约束、缺失对角、只读目标图共享、图失配、数值失配、
非有限变换、Jacobi 和块 Jacobi 多载荷等价。完整本地套件为 188 项测试与 53 个
子用例，全部通过。

T3/T4 六个载荷因子均满足：冷路径与预备路径解逐项相同，应变能差为零；真实
自由残差相对载荷范数最大值为 `1.13e-11`，全局平衡相对量最大值为
`4.45e-13`。每次 CG 报告的真实残差均不超过其报告阈值。

## 声明边界与结论

本记录固定已装配 CSR 刚度和约束集合，测量多个右端项的约束变换、块 Jacobi 与
CG；不包含元素装配、非线性切线更新、MPI、GPU 或直接法。倍率只属于该 macOS
arm64 环境，不外推 Windows/Linux。

P3 的重复稀疏生命周期已经从“图回填局部优化”推进到真实 T3/T4 完整约束求解。
仍需 Linux 快检确认平台无关实现，并继续处理直接元素到 CSR 的峰值内存、SIMD
和更强可替换预条件器。该结果不单独提升 Gate 2 为 `verified`。
