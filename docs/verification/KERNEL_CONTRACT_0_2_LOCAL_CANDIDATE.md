# Kernel Contract 0.2 本地候选报告

**日期：** 2026-09-20

**成熟度：** 契约本地候选通过；Gate 2 仍为 `implemented`

**产品对象：** AgentFEM 的未来线性静力计算入口

## 交付结论

Kernel Contract 0.2 已把现有 T3/T4 自主线性力学主链接到 AgentFEM 可消费的
稳定 JSON 边界。调用方现在可以先预检资源计划，再执行同一计划，并得到位移、
应变、应力、守恒量、运行身份、成熟度和摘要证据。实现没有新增第二套装配或
求解逻辑，也没有把当前 AF-IR 变成 Native 的内部依赖。

0.1 二维稳态热传导继续可执行，并保持旧结果形状。0.2 是新的默认版本，新增
T3 平面应力/应变、T4 三维线弹性、常体力、位移约束、边/面力、分区材料、
力学 VTK 与执行前资源计划。动力学 JSON 契约留到 Gate 3 证据闭合后处理。

## AgentFEM 安全边界

- `plan_kernel_request` 不装配、不求解，返回自由度、稀疏规模与内存保守上界；
- `run_kernel_request` 使用规划阶段同一个 `ExecutionPlan`，执行器会复核计划与
  问题是否仍一致；
- 规范请求、计划和执行证据分别拥有 SHA-256，便于 AgentFEM 追踪一次计算；
- 结果显式返回 `implemented`，成功运行不会被解释为科学验证；
- 重要新增诊断与说明以中文为主，稳定 JSON 字段和错误码保持英文。

## 本地证据

- 0.1 兼容：旧版热传导成功，结果不增加 0.2 专属计划与证据字段；
- T3：预检与执行计划摘要相同，位移为二分量，全局载荷—反力平衡通过；
- T4：三分量位移、六分量应变/应力和全局平衡通过；
- 失败：二维请求使用 `z` 分量时，在装配前准确定位到
  `$.dirichlet[0].component`；
- 产物：三维力学 VTK 保持相对路径并绑定 SHA-256；
- CLI：`--plan-only` 返回计划且不包含结果字段；
- 完整本地套件：194 项测试、53 个子用例通过；Ruff、格式和独立性扫描通过；
- 依赖：只复用 Python 标准库、NumPy 和已有自主 C++20 内核，没有新增依赖。

## 验收边界

本报告只关闭 G2-11 的本地 JSON 产品接纳项。新增 Python 契约、Schema、示例与
安装包内容仍需在本源提交上通过 Windows x86_64、Linux x86_64、macOS
x86_64/arm64 Tier-1 验收，才能关闭 G2-12 并评估 Gate 2 是否提升为
`verified`。既有 ABI 1.4 三平台记录不能替代本次安装包与契约变更的验收。

## 独立性

本增量依据本项目自有数学规格、问题类、资源计划和执行收据独立实现。没有读取、
复制、翻译、重排或 AI 改写 DOLFINx、Basix、UFL、FFCx、Akantu 或其他第三方
有限元实现源码。NumPy 是可替换的通用数组基础，不拥有有限元语义。
