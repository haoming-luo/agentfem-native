## 轻量数学证据

热：线性 patch/精确热通量、总热容、绝热均匀产热守恒、Robin 符号、时间一阶。
热弹性：自由膨胀/完全约束、平面应变 sigma_zz、热链与能量方向导数。
有限变形：材料与全局切线差分、客观性、自由内点 affine patch、力控大伸长、
翻转拒绝/减步回滚、有限热伸长零应力、非正定 GMRES 与奇异失败。
AT2：恒定损伤解析值、KKT、预裂纹轮廓细化、能量单调、不可逆、E/Gc 整体单位
缩放不变。T4 动力：质量守恒/正定、离散模态 Newmark 二阶、逐位重启。

新增运行安全：零载荷悬浮部件也拒绝、孤立节点拒绝、刚体约束平移/单位不变，
非法参数预检前置、取消不提交试探、输出失败保留旧文件、原始请求不可被覆盖。
这些检查不证明所有内部机构都被预检识别。

三维横向约束条带新增解析证据：E=100、nu=.25、rho=2，连续纵波速
sqrt(60)=7.7459666924，最低圆频率 pi*c/2。8/16/32 轴向划分的最低频率
相对误差分别约 8.54e-4、2.13e-4、5.33e-5；32/64 划分的两截面脉冲波速

纵向约束模型不能外推三维横波、自由表面反射或复杂工程网格。

Newmark 上一已接受加速度作初猜的实验只保留 Python `warm_start=True`，默认
False，0.3/0.4 JSON 均不加入该选项。macOS arm64 五次交错、固定 K/M 之后的

迭代总数从 2001 增至 2045。小幅正负差异不足以支持默认晋级。完整场/反力/能量
差异在原容差内，最大观测字段差约 2.35e-11；同策略重启逐位等价，突变载荷
亦有检查。原始记录为 `benchmarks/results/2026-10-27-newmark-initial-guess.json`，
明确排除网格、装配和导入时间，不宣称 Windows 性能。

固定矩阵范数复用则有更稳定的收益：相同版本、相同冷初猜策略，干预组每个 RHS
重新扫描行绝对和，对照组复用预条件器所绑定的数值快照范数。四档完整 100 步
积分五次交错中位倍率约 1.07、1.09、1.11、1.13，所有接受场/反力/能量逐位相同，
