## 本地证据

- macOS arm64：完整 250 项 unittest、Ruff、格式、独立性扫描通过。
- C++20 严格编译契约、C11 头文件契约、ASan/UBSan 通过。当前本机没有 CMake，
  使用系统 Clang 直接编译相同契约；CMake/MSVC 路径由 CI 负责。
- 首轮 CPython 3.11 Stable ABI wheel 构建并在仓库外、中文/空格虚拟环境安装；
  安装环境只有 NumPy，无 SciPy/PETSc/MPI；最终候选重新构建、复装后执行全部
  250 项测试通过（3 项可选 SciPy 测试跳过）。十个多物理案例亦在首轮安装态
  成功，最后一轮连通分量变更经完整安装态套件覆盖。
- 有限变形力控单位体达到 50% 伸长，二维/三维 min J 约 1.4999999996，
  最终自由残差约 1.26e-8/1.01e-8，满足各自按载荷尺度计算的停止阈值。
- 预裂纹加载/卸载示例最终自由残差约 7.86e-14/1.45e-13，最终损伤 KKT 为 0。
  这是离散平衡证据，不是工程裂纹扩展实验验证。

## 轻量数学证据

热：线性 patch/精确热通量、总热容、绝热均匀产热守恒、Robin 符号、时间一阶。
热弹性：自由膨胀/完全约束、平面应变 sigma_zz、热链与能量方向导数。
有限变形：材料与全局切线差分、客观性、自由内点 affine patch、力控大伸长、
翻转拒绝/减步回滚、有限热伸长零应力、非正定 GMRES 与奇异失败。
AT2：恒定损伤解析值、KKT、预裂纹轮廓细化、能量单调、不可逆、E/Gc 整体单位
缩放不变。T4 动力：质量守恒/正定、离散模态 Newmark 二阶、逐位重启。

新增运行安全：零载荷悬浮部件也拒绝、孤立节点拒绝、刚体约束平移/单位不变，
非法参数预检前置、取消不提交试探、输出失败保留旧文件、原始请求不可被覆盖。
这些检查不证明所有内部机构都被预检识别。

## 性能边界
