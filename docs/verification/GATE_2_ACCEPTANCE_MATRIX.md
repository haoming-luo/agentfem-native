## 判定规则

- G2-01 至 G2-10 及 G2-11 直接 API 证据通过后，只形成 Gate 2 本地科学验收
  候选；版本化 JSON Contract 0.2 仍是独立产品接纳项；
- G2-12 未关闭前，整体成熟度保持 `implemented`；
- 任一收敛、残差、平衡或差分断言失败时记录最小反例，不扩大容差；
- FEniCSx 等第三方仅在隔离的里程碑验证中提供少量黑盒交叉证据，不能替代本表
  中的解析、守恒和收敛依据。
