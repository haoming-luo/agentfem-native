# Kernel Contract 0.3 线性动力本地候选报告

**日期：** 2026-09-20  
**状态：** 本地候选通过；等待 Linux 快检与 Gate 3 三平台候选验收  
**成熟度：** 契约能力 `implemented`，不提前提升 Gate 3

## 产品结论

AgentFEM 现在可以通过一个版本化、JSON 安全且不依赖当前 AF-IR 内部形状的边界，
完成 T3 线性动力学的资源预检、预算控制、执行、结果审查和检查点续算。0.1
热传导与 0.2 线性静力请求继续兼容；0.3 只扩展限定动力范围，不改变旧版本语义。

## 已接纳能力

- 二维 T3、小应变、无阻尼线性动力，零位移固定约束；
- 集中质量中心差分，以及一致/集中质量 Newmark 平均加速度；
- 常数或分段线性标量时间曲线乘以自主装配的空间载荷；
- 每节点初始位移/速度、完整状态历史、能量/外力功/平衡误差和约束反力；
- 带确定性 SHA-256 的最后接受状态检查点及逐位等价续算；
- JSON 资源预算，以及调用方 `ExecutionContext` 的取消和进度边界；
- 请求、计划和执行摘要绑定的证据收据，以及稳定失败码和字段路径。

## 无装配预检边界

0.3 新增 T3 动力专用规划器。它只读取网格计数、积分步数、质量形式和装配路径，
保守估计稀疏矩阵、状态历史、求解工作区和线程工作区；不会构建质量或刚度矩阵。
定向测试用失败替身守住这一不变量。预算和计划匹配通过后，执行入口才装配自主
T3 算子，并在自由自由度系统上复核中心差分稳定上限。

## 本地证据

- 208 项全库单元测试通过；
- 0.3 的计划与执行摘要一致，结果可用严格 JSON 编码；
- 6 步不中断轨迹与 3 步检查点加 3 步续算的最后状态逐位一致；
- 步数预算在装配前以 `budget.steps_exceeded` 失败；预取消以
  `execution.cancelled` 和可重试建议失败；
- 中心差分配一致质量、载荷曲线覆盖不足等不支持组合在执行前失败；
- 0.1 热传导和 0.2 T3 静力兼容测试通过；
- 可运行示例 `examples/linear_dynamics_t3_request.json` 的 `--plan-only` 与正式
  执行均通过，20 步执行返回 21 个接受状态和第 20 步检查点；
- Ruff、格式与独立性扫描通过；macOS arm64 CPython Stable ABI wheel 离线构建、
  隔离安装并从仓库外执行示例成功，安装态报告 0.3.0、原生扩展可用、20 步执行
  返回 21 个接受状态。

## 明确未声明

本候选不支持阻尼、非零/时变位移约束、T4 动力、自适应时间步、时间序列 VTK、
非线性、MPI 或 GPU。接口可用不等于外部实验验证或生产成熟；G3L-12 的最新
Windows/Linux/macOS 安装态验收关闭前，Gate 3 限定线性范围保持
`implemented`。
