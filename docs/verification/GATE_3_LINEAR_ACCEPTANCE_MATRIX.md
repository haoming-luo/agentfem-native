## 验收范围

本矩阵只验收 AgentFEM Native 当前自主掌握的无阻尼线性二阶系统：

```text
M a(t) + K u(t) = f(t)
```

生产范围包括集中质量中心差分、一致质量 Newmark 平均加速度、零位移固定约束、
T3 小应变弹性半离散系统、能量/外力功/反力账本，以及摘要绑定的检查点重启。
阻尼、非零或时变位移约束、材料/几何非线性、自适应减步、MPI 和 GPU 不在本次
线性验收声明内；它们必须在各自规格和证据闭合后另行晋级。

## 判定规则

- 只有 G3L-01 至 G3L-12 全部关闭，才能把本表限定范围提升为 `verified`；
- Linux 快检证明当前增量可集成，但不能替代 G3L-12 的三平台候选验收；
- `verified` 不代表外部实验 `validated`，也不代表整个 Gate 3、整体内核或大规模
  生产性能已经完成；
- 任一阶数、稳定性、能量、平衡、重启或跨平台断言失败时保留最小反例，不通过
  放宽容差掩盖差异；
- FEniCSx 等第三方只能在单独任务中作为少量黑盒交叉比较，不能成为唯一真值。
