# 五小时 Gate 2 快速冲刺

**日期：** 2026-09-13  
**目标：** 把 T3/T4 从“已有许多分散证据”推进为一个可审查的 Gate 2 本地
验收候选，不在一次短冲刺里铺开新的验证平台。  
**产品方向：** 为 AgentFEM 提供可替代 FEniCSx 等第三方有限元内核的自主
线性固体力学执行主干。  
**成熟度边界：** 本冲刺最多形成 Gate 2 本地验收候选，整体成熟度仍保持
`implemented`；不越过尚未完成的 CPU 并行和 Tier-1 三平台验收，不直接把
Gate 2 标为 `verified`。

## 一、冲刺成功标准

五小时结束时必须同时交付：

1. 一张不超过十二项的 T3/T4 Gate 2 验收表，逐项链接已有或新增证据；
2. 两个真实求解收敛竖切：二维 T3 与三维 T4，各使用三个小网格层级；
3. 三到八个新增高信息测试，覆盖正常、数学不变量和失败边界，不追求覆盖率数字；
4. 现有 `plan -> execute -> explain` 记录能明确报告维数、单元、装配路径、求解
   提供者、残差/平衡和真实成熟度；
5. 一份本地验收记录，包含数值差异、环境、已知限制和下一未关闭项；
6. 全部 L1 检查与相关 C/C++ 契约通过，代码提交只触发一次 Linux 快检。

## 二、五小时时间盒

### 00:00–00:25：冻结验收边界

- 从现有测试和报告提取证据，不重新制造已经通过的 patch、刚体模态和材料区域
  测试；
- 建立最多十二项的 Gate 2 验收表，将每项标为“已有、此次补齐、后续 Gate”；
- 固定两个制造解、三档网格和误差/平衡判据，避免开发中途改变成功标准。

**退出物：** 明确的缺口清单和只运行相关测试的 L0 命令。

### 00:25–01:35：补齐 T3 真实求解收敛

- 选择具有常体力、可施加解析边界位移的二次位移场；
- 在三个小型三角网格上实际完成装配、约束、稀疏求解和恢复；
- 同时检查位移误差趋势、自由残差、反力平衡和能量一致性；
- 对参考实现、向量化路径和 C++ 体积装配做完整结果差分。

**退出物：** 一个参数化收敛测试及其关键失败案例，而不是一组大型 golden 文件。

### 01:35–02:45：补齐 T4 真实求解与畸变稳健性

- 对三维四面体使用对应的二次位移制造解和三个小网格层级；
- 增加一个有界畸变但合法的网格案例，检查体积、方向置换、残差与结果稳定性；
- 保留解析/守恒依据，不以 T3 或另一程序的结果作为唯一真值。

**退出物：** 一个 T4 求解收敛测试、一个畸变/方向不变量或明确失败测试。

### 02:45–03:35：收紧 AgentFEM 可消费证据

- 只扩展现有 `plan -> execute -> explain` 记录，不新建通用验证服务；
- 明确输出 `dimension`、`element_family`、`assembly`、`provider`、残差、反力/
  能量平衡、资源估算和成熟度；
- 对不支持的单元、过高资源预算和过期计划给出稳定错误码与中文诊断；
- 不在本冲刺冻结完整 Kernel Contract 0.2，也不依赖当前 AF-IR 内部形状。

**退出物：** Agent 可以判断“算了什么、结果是否闭合、证据到哪一级”。

### 03:35–04:20：轻量性能与替代路径检查

- 选择小、中、大三个本地代表规模，只运行已有 T3/T4/CSR 基准；
- 比较 C++ 热路径与项目维护的有限元参考实现的完整输出和中位时间；
- 检查没有隐藏稠密化、意外复制或 Python 热循环回退；
- 不在工作站设置脆弱的硬墙钟门槛，不在本轮安装或日常调用 FEniCSx。

**退出物：** 一份可复现 JSON 记录和诚实的性能/内存边界。

### 04:20–05:00：本地验收与交付

- 运行完整 Python 测试（当前基线 169 项）、独立性、格式、C/C++ 契约和
  sanitizer；
- 更新 Gate 2 验收表、验证报告、能力清单、限制和来源记录；
- 只提交这一批可审查能力并推送一次，由普通 Linux 快检验证安装和便携契约；
- 若任一科学断言失败，保持 `implemented`，记录最小反例，不扩大容差。

**退出物：** 一个干净提交和明确的“通过/未通过/剩余”结论。

## 三、FEniCSx 等外部对照如何安排

本冲刺不把 FEniCSx 做成日常依赖，也不开发庞大的跨软件测试框架。Gate 2 本地
候选稳定后，另开一个隔离验证任务，仅选二维单轴/悬臂和三维立方体两个或三个
公开输入案例，通过文件交换比较位移、应力、反力与能量。该结果是交叉证据，
解析解、守恒和收敛仍是主要真值。

Akantu 或其他力学内核只有在同一输入能够低成本表达时才增加一个代表案例；不能
为了“对照数量”牺牲内核开发时间。任何外部对照都只使用公开接口和数值输出，
不得读取或传递其实现源码。

## 四、明确不在这五小时内做

- 不自研 NumPy、BLAS、LAPACK、通用稀疏排序或完整 AMG；
- 不引入新的测试框架、验证数据库、仪表盘或大规模 golden 数据；
- 不同时启动 Q4/H8、全局非线性、MPI、GPU 或接触；
- 不把 CPU 线程化草率塞进科学闭环；它是紧随本冲刺之后的 P3 专项；
- 不运行完整 Windows/Linux/macOS Tier-1 矩阵，除非本轮结果被正式提名为 Gate
  候选。

## 五、冲刺后的唯一下一步

若本地 Gate 2 科学候选通过，下一冲刺只做 P3 CPU Production Spine：预构建
CSR/BSR 图、C++ 数值回填、确定性静态分块、线程数不变量和 1/2/4/8 线程基准。
完成后再运行一次 Gate 2 Tier-1 验收。这样既保持高性能目标，也避免科学验证与
并行重构同时变化而难以定位错误。
